
# 🎮 Tic-Tac-Toe Deluxe

A visually stunning two-player Tic-Tac-Toe game built with HTML, CSS, and JavaScript.
This project features a sleek animated UI, smooth gameplay, and keeps track of player scores and draws.

## 🚀 Features

- Two-player gameplay — Player X vs Player O
- Score tracking — Tracks wins for Player X, Player O, and draws
- New Round button — Start a new game without resetting scores
- Reset All button — Reset the entire game and scores

## 🖥 Demo

You can view the live demo by opening `index.html` in your browser.

```bash

```

3. Open the game in your browser:

Double-click `index.html` or open it via your browser.

## 🎯 How to Play

- Click any empty cell to place your mark (X or O).
- Players alternate turns until someone wins or the board is full.
- When the game ends:
  - A winning line is highlighted.
  - Scores update automatically.
  - A new round starts automatically after 2 seconds.
- Use "New Round" to restart without resetting scores.
- Use "Reset All" to clear everything.
